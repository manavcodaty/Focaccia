# Focaccia UI Redesign Migration Ledger

Date opened: 2026-07-13
Date finalized: 2026-07-13

This is the parity ledger for every production route and each major reusable presentation component. “Retained” means behavior stays in the existing provider, hook, API, context, storage, validation, or lifecycle code. Visual evidence paths are local ignored QA targets until populated; a path is not proof by itself. Status may become **Verified** only after the listed functional and rendered checks genuinely pass.

Test keys:

- **T-TKT**: Tickets unit/source tests, typecheck, production build, and route browser checks.
- **T-WEB**: Organizer unit/source tests, production build, and route browser checks.
- **T-ENR**: Enrollment unit/coverage and typecheck; full device rendering is user-owned.
- **T-GAT**: Gate unit/coverage and typecheck; full device rendering is user-owned.
- **QA-WEB**: ignored evidence in `/Users/manavcodaty/.codex/visualizations/2026/07/13/019f5a4b-73f0-7c82-9ff7-faab055e0bdc/web-review/`, plus browser interaction, console-error, focus, and overflow notes.
- **QA-MOB**: source/accessibility review plus unit/coverage/typecheck evidence; simulator, physical-device, camera, and full mobile E2E rendering were intentionally left to the user.
